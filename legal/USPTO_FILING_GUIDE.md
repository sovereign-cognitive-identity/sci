# USPTO Trademark Filing — Sci

## Action required before public launch

File a trademark application for "Sci" at USPTO.gov before the HN Show post.
A pending application (`™`) gives you priority date from filing.
Full registration (`®`) takes 8-12 months but priority is from the filing date.

## Filing details

**Go to:** https://www.uspto.gov/trademarks/apply

**Use TEAS Plus** (cheaper, ~$250/class vs ~$350 for TEAS Standard).
TEAS Plus requires using USPTO's pre-approved ID manual — use the description below exactly.

### International Class 042

**Services description** (copy exactly for TEAS Plus pre-approved ID):

> Software as a service (SaaS) featuring software for artificial intelligence memory management, cognitive identity management, and privacy-preserving artificial intelligence proxy services; software as a service (SaaS) featuring software for routing queries to artificial intelligence models

If the pre-approved ID doesn't match, use TEAS Standard with this custom description:
> Providing a software platform as a service for managing AI agent memory, anonymizing user identity for AI processing, and routing queries to artificial intelligence language models

### Specimen (needed if using 1(a) — skip if using 1(b) Intent to Use)

Intent to Use (1(b)) does not require a specimen at filing. You'll need to submit one when you file the Statement of Use after the service launches. At that point, a screenshot of the Sci website or app showing the mark in use is sufficient.

## After filing

1. Note the serial number and filing date
2. Update `TRADEMARK.md` with the serial number and filing date
3. You can now use ™ next to "Sci" everywhere
4. USPTO will examine the application (~3-6 months)
5. If approved, it publishes for opposition (30 days)
6. If no opposition, registration issues (~10 months total)
7. File Statement of Use within 6 months of Notice of Allowance (or request extensions)
8. Once registered, update ™ to ®

## Search first

Before filing, do a quick search to confirm "Sci" isn't already registered for software/SaaS:
- https://tmsearch.uspto.gov
- Search: "SCI" in International Class 042
- Also search phonetic variants: "SKY", "SIE"

A conflict with a registered mark for similar services would block registration.
